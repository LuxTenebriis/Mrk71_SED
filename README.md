# Unresolved Photometric Binaries Project

## Mrk71_SED
Last updated: 09/23/2026

This notebook creates magnitude-versus-filter plots for stellar populations in
Mrk 71.

### Regions 
- Knot A
- Knot B
- Region II

### Stellar Categories
- MS: main-sequence star candidates
- Y/R: yellow/red star candidates
- RSG: red-supergiant star candidates
- 
### Notebook Layout
- **Setup:** Imports packages, defines file paths, and identifies photometric columns.
- **Functions:** Defines functions for cleaning data and creating plots.
- **Knot A:** Processes and plots Knot A.
- **Knot B:** Processes and plots Knot B.
- **Region II:** Processes and plots Region II.

### Data Notes
- Smaller magnitudes indicate brighter measurements.
- The magnitude axis is inverted in the plots.
- Original catalogs should not be overwritten.
- Missing or unusable measurements are represented as `NaN`.
